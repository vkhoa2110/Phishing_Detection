# Tài liệu PhishLens

Tài liệu hiện hành được gom theo mục đích, không tạo thêm một file ghi chú cho mỗi phiên bản thử nghiệm.

| Cần tìm | Đọc ở đâu |
|---|---|
| Cài đặt, dùng giao diện, gọi API, xử lý lỗi | [Sử dụng ứng dụng](guides/USAGE.md) |
| Embedding, corpus và chỉ mục | [Cài đặt RAG](guides/RAG.md) |
| Luồng xử lý, quy tắc kết luận, profile stable/candidate | [Kiến trúc](architecture.md) |
| Tổ chức mã nguồn, quy ước, migration và lịch sử | [Phát triển](development.md) |
| Dữ liệu, nhãn, phép so sánh và chỉ số | [Đánh giá](evaluation.md) |
| Những kết quả đã có và giới hạn | [Kết quả](results.md) |

Các thiết kế cũ theo phiên bản đã được gom vào các trang trên. Nội dung đầy đủ trước lần tổ chức lại còn trong [mốc Git 479c966](https://github.com/vkhoa2110/Phishing_Detection/tree/479c96612ca79d3e1de2d37df22d82ce19e09f23/docs). Xem [cách tái lập bằng worktree](development.md#tai-lap-lich-su) để dùng đúng source hash của thực nghiệm cũ.

`reports/` là tài liệu học thuật cục bộ, không thuộc bộ tài liệu được commit.
